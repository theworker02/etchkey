# etchkey

Etch timestamps and key durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/etchkey/

## Install / run

```bash
git clone https://github.com/theworker02/etchkey.git
cd etchkey
node src/cli.js
node --test
```
